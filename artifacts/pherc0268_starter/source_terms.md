# Credits, terms and scope

CT source: Vesuvius Challenge, PHerc0268, `20251110183117-8.640um-1.2m-116keV-masked.zarr`, level 0. This package contributes crop curation/provenance and portable access code; it does not claim original CT acquisition, fiber annotations or ink truth. Selection/filter/training work originated in Ryan Gurganious's retained Vesuvius research repository. No CT pixels or model weights are distributed in this starter.

The exact PHerc0268 volume entry in the official [CT metadata catalog](https://vesuvius-challenge-open-data.s3.us-east-1.amazonaws.com/metadata.min.json) declares **CC BY-NC 4.0** at `/samples/PHerc0268/volumes/20251110183117/properties/license`. This asset-specific evidence supersedes the uncertainty recorded during the initial starter preparation. The [public source catalog](https://huggingface.co/datasets/darthceltic85/argus-research-resources/blob/main/ct/source_catalog.json) preserves the exact entry, license link and catalog hash; the [access receipt](https://huggingface.co/datasets/darthceltic85/argus-research-resources/blob/main/ct/source_metadata_access.json) records anonymous HTTP 200 responses for the source Zarr metadata. Those were metadata-only checks, with no CT chunk download or decoding.

Follow the attribution, noncommercial and change-notice requirements in the [asset license](https://creativecommons.org/licenses/by-nc/4.0/). The broader [data documentation](https://scrollprize.org/data) and [legacy data-server license](https://dl.ash2txt.org/LICENSE.txt) also remain linked for context; this release points to the original S3 pixels rather than mirroring them. The starter's default command remains an offline plan, and original-host reconstruction requires explicit source-fetch and terms flags.

Use the citation for **Vesuvius Challenge — CT Scans of Herculaneum Papyri** on the data documentation page, with the exact PHerc0268 scan URI and this selection recipe. Do not attribute this newer scan to the legacy EduceLab acquisition merely because the portal also hosts that dataset.

The source and metadata in this starter are offered under its MIT code/documentation license. The retained Vesuvius repository license is Ryan's MIT code license; current ARGUS public code uses Apache-2.0. Those licenses do not license CT pixels. The separately published representation checkpoints have their own model cards and release terms at [ARGUS research baselines](https://huggingface.co/darthceltic85/argus-research-baselines).

The original selection's density criterion was nonzero fraction >=0.5, a material-content gate. It is not an ink or fiber label. Actual per-field density values were not retained in this manifest. The source is isotropic raw CT at 8.640 micrometers, unlike surface-relative ink-evaluation inputs.

Initial preparation performed no original-host fetch, real CT decoding, visualization, inference, training, checkpoint loading, reading claim or Google-form submission. The later access check fetched only JSON metadata and license records. Hashes cover retained compressed bytes; they do not prove decoded scientific content. Synthetic tests and a mocked source verify code paths independently of real CT. Actual original-source reconstruction has not been executed in this release.
