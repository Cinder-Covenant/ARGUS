ARGUS: a reproducible scroll-processing workbench, with demonstrated improvements to inference reliability, rendering and paired-output efficiency, plus a curated research collection of CT fields, trained baselines and failure-analysis resources.

We are Ryan Gurganious and Daine Ball, Team Cinder Covenant. ARGUS connects community tools with explicit credit to detector, renderer, CT, annotation, registration and architecture authors. The evidence index gives source, checks, results, revisions and limitations.

1. Which scroll data we used

The public control uses PHerc0139 w016 (640-by-896), published ink/supervision/validation masks and a pinned ink_9um checkpoint. We investigated numerical failures on PHerc1667 w029, renderer metadata using PHerc0009B geometry, and renderer output using retained PHercParis4 CT. Hecate efficiency was measured on an exposed PHerc0139 control (16-by-256-by-256). Exploratory PHerc1203 work has not established a reading and is not claimed as discovery.

A file-manifest audit lists 4,399 candidates across six scrolls: 4,398 have expected chunk filenames; one partial is quarantined. Complete counts: PHerc1203 832 high-resolution 256-cubed fields, PHerc0268 342 native 128-cubed fields, and 3,224 coarse fields (PHerc0800 374, PHerc1447 1,862, PHerc0139 919, PHerc0009B 69). The public index records 3,566 known native origins, 832 unresolved PHerc1203 origins, 30 exact duplicate source boxes and 43 source-edge containers with clipped valid bounds. Complete containers total 18,295,712,472 retained compressed bytes and 21,437,087,744 logical voxel entries. These are curated community subvolumes, not new scans, unique coverage or independent examples; CT was not decoded for this audit. PHerc1203's 2.403-micrometer material supports structural/self-supervised research, not low-resolution unread-reading evidence. PHerc0009B raw CT was in coarse pretraining, so its later evaluation is not physically unexposed.

2. How this helps researchers read scrolls

ARGUS provides an executable known-data control route: identify scroll/volume, acquire a specified crop and labels, verify the checkpoint, prepare input, run inference, evaluate the declared region and retain evidence. The release includes the interface, diagnostics, identity checks, exposure accounting and regression tests. It is a reference workflow starting from an existing surface volume, not an autonomous whole-scroll reader.

The public Workbench also runs a bounded Hecate control on one exposed PHerc0139 field. A guarded job binds input, preparation, runtime and checkpoint identities, reports progress, and displays 2D/3D outputs whose hashes exactly match the pinned control. Other inputs are refused. This is a provider integration, not a reading or accuracy result.

The broader work curates CT selections, trains representation baselines, and releases computed atlas, geometry, exposure and defect analyses. All six original CT acquisitions are already public; our selected local copies were private. We now link their exact original volumes and per-volume CC BY-NC 4.0 evidence instead of uploading duplicate pixels. We credit Vesuvius Challenge, external PHerc1203 registration by Shuhan Yang, architectures and upstream annotations. Four own trained checkpoints (PHerc1203/PHerc0268 MAE, small PHerc0268 DINO/iBOT, multiscroll coarse DINO) totaling 4,125,955,140 bytes are now publicly downloadable with cards, configurations, source pins/notices and a metadata-only verifier. They are representation baselines, not qualified ink detectors.

The PHerc0268 starter gives 342 exact origin/hash records, a deterministic 24-field selection, a local Zarr loader and bounded opt-in original-host reconstruction. It defaults to a no-network dry run and bundles no CT/weights. Metadata/hashes and synthetic fixtures were checked; live-source reconstruction/target decode were not run. The reader guide connects it to ARGUS controls and engineering receipts.

A concrete failure motivated Villa #1897: on a GTX 1660 Ti, FP16 produced non-finite predictions and a 99.8%-zero TIFF while reporting success. The PR fails explicitly on non-finite output and adds checkpoint-aware input warnings with optional strict refusal. Guarded full-precision output exactly matched the corresponding unmodified output. We credit separate upstream precision-selection work (#1890); finite output does not prove absence of ink.

3. What our changes enable

Villa #1901 records effective surface geometry/settings and fixes a writer defect: pyramid-disabled output advertised five nonexistent levels. Corrected metadata lists only the written level; tested pixels and physical scale are unchanged. Regression covers pyramid on/off, with/without --pre, complementing existing malformed-store reader handling.

Hecate PR #1 reuses model features when both 2D/3D outputs are requested, replacing duplicate feature evaluation with one tiled pass and disk-backed accumulation. Weights and outputs are unchanged. This is a reusable provider contribution developed through ARGUS.

ARGUS's runtime-isolation correction prevents one runtime from presenting another runtime's local holdings as its own. Before/after UI evidence and three regression fixtures accompany it.

The derived download includes the 1,505-site PHerc1203 atlas/methods; 63 NumPy fields over 21 surfaces/seven scrolls; 13 XYZ meshes/generation tags; EXP7, coordinate diagnostics and exposure records. Atlas classes are automatic profiles, not dense mappings, human labels or certified sheets/ink. The 17 paired flatten comparisons are mixed/outlier-sensitive; input area is not new unwrapping. Meshes are our seed/run outputs of Villa's grower: one corrected U03 local geometry PASS (82-by-82, 2.0924 cm2), nine PHerc0268 diagnostic and three explicitly suspect PHerc0125/PHerc1451 fixtures. PASS does not certify CT continuity/reading. EXP7 has 204 synthetic positives, 24 topology defects, 48 reference configurations and 88 planted defects, not independent surfaces. Archived paths/source and incomplete fresh-machine reproduction are disclosed in the guide.

4. Evidence and status

Independent rescoring of PHerc0139 reproduces ROC AUC 0.772238 and average precision 0.578875 on 90,367 validation pixels (22,765 positive); validation and supervision masks are disjoint. This known-domain control is not a new detector result or cross-scroll proof.

The renderer correction passed nine integration tests and three focused C++ targets locally; all 12,288 retained Paris4 control pixels are exactly unchanged. The public package includes failure, fix, hashes and commands.

Three alternating fresh-process actual-CLI Hecate pairs reduce median launch-to-exit from 17.8357 to 11.5913 seconds (35.01%). Outputs are bitwise equal across 65,536 2D pixels and 1,048,576 3D voxels; feature calls drop 98 to 49. GTX 1660 Ti 6 GiB, FP32, batch one, two CPU threads; no thermal pause, max 68 C. Receipt includes memory/resource bounds. Timing includes startup/output writing, excludes preparation/UI transport; OS cache was not forced cold. One small exposed field, with no whole-scroll, 2D-only, 2.4-micrometer or accuracy extrapolation.

Three larger 16-by-512-by-512 PHerc0139 CLI pairs are also exactly equal (262,144 2D pixels, 4,194,304 3D voxels; feature calls 450 to 225). Median 163.010s versus 57.328s is confounded by unequal cooling pauses (55–99s versus ~22s). The smaller pause-free comparison is cleaner. These runs used exposed controls.

Retained scores: PHerc0268 MAE full-population AUC 0.5404; grouped small-DINO probe 0.5641; PHerc0009B coarse-DINO prototype/linear probes 0.4573/0.5123 (raw-CT pretraining exposure). PHerc1203 MAE validation loss 0.5455 is reconstruction, not ink. These modest/negative baselines do not qualify a detector; audit streamed checkpoint hashes but did not load or rerun models.
